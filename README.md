# CoGig — Cooperative Gig Services Platform

Frontend MVP for **Problem 89: Cooperative Gig Services Platform for Household & Community Services**.

## Stack
- React 18
- Vite
- React Router
- Lucide React
- Plain CSS (responsive, no backend dependency)

## Run locally
```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Included screens
- Home / landing page
- Find Services marketplace
- Local Workers directory
- Post a Job flow with success state
- Customer Dashboard
- Sign In screen
- Responsive mobile navigation
- Mock marketplace, worker, job and cooperative-impact data

## Backend integration later
The UI is intentionally frontend-only. API/service layers can be added next for authentication, worker profiles, job posting, offers, chat, payments, ratings, location services, notifications and cooperative earnings.
